Smileschool Project Description
 Web page for a SmileSchool, an online platform dedicated to helping people learn the art of smiling through expert-led tutorials.
The homepage introduces users to SmileSchool's instructors, popular tutorials, membership benefits, testimonials, and frequently asked questions.
# Features
1. Hero Section with Smilesection logo, Navigation links, background image.
2. Expert Instructors section
3. Testimonials section 
4. Popular Tutorials section 
5. FAQ section.
